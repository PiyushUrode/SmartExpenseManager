# SmartExpenseManager

SmartExpenseManager is a Java-based application designed to manage
family income, expenses, budgets, and savings dynamically.

## Features
- Supports small & large families
- Multiple earning members
- Multiple income sources
- Category-wise expense tracking
- Monthly budget & savings calculation
- Clean OOP & layered architecture

## Technologies
- Java
- OOP (Encapsulation, Abstraction, Inheritance, Polymorphism)
- Eclipse IDE
- Git & GitHub

## Project Structure
- model
- service
- util
- enums
- app

## Status
Core system completed (Phase 1–4)
